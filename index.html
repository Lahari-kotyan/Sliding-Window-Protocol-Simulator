Protocol Comparison Summary

Metric One-Bit SW Go-Back-N Selective Repeat

Computer Networks Protocol Reference Guide

1. One-Bit Sliding Window (Alternating Bit)

Operates with a strict window size of N = 1. Only one frame is allowed in transit. Sequence numbers alternate between 0 and 1. Retransmits the frame upon timeout.

2. Go-Back-N (GBN)

Allows up to N unacknowledged frames in transit. Uses cumulative acknowledgements. Discards out-of-order frames at the receiver. Single base timer retransmits all unacknowledged frames in the window upon timeout.

3. Selective Repeat (SR)

Sender and Receiver both maintain a window of size N. Receiver buffers out-of-order frames. Individual ACKs are returned. Sender maintains per-frame timers and retransmits only missing frames.

4. Metric Calculations

  • Throughput (fps): Delivered Frames / Total Time (seconds)
  • Efficiency (%): (Original Unique Frames / Total Transmissions) × 100%
